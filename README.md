# 星裂突击 SkyRift · Web

[在线试玩](https://lchigo.github.io/skyrift-web/)

竖版肉鸽弹幕射击游戏的浏览器发行版。

## 操作

- WASD / 方向键 / 按住鼠标左键拖动：移动。
- 空格 / X / 鼠标右键：大招。
- 1–4：升级选择；R：重抽；Esc：暂停。
- 触屏设备使用游戏内触控操作。

画布随浏览器窗口大小调整，背景铺满页面，游戏内容保持比例。首次点击游戏后启用音频。

存档保存在当前浏览器的网站存储中。清除网站数据会清除本地进度，不同域名及浏览器的存档独立。

此仓库仅包含 Godot Web 发行文件；更新时整体替换发行文件并保持文件名不变。
